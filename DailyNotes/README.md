# DailyNotes（索引）

日常のメモ・作業ログの起点。ここに書いた最新情報を AI が Projects / Tasks へ転記する。
毎朝 `/start-day` で作る。

## 命名規則
- 週フォルダー: `YYYY-Wxx`（ISO週番号。例: `2026-W41`）
- 日次ノート: `YYYY-Wxx/YYYY-MM-DD.md`
- 週の振り返り: `YYYY-Wxx/weekly-review.md`

## ノートの書式
```markdown
# YYYY-MM-DD（曜）

> **今日やること：トップ5／確認する依頼 N件／今日が期限 N件**

## 今日のトップ5
1. 🔴 **タスク内容**（補足）― 期限 MM/DD・案件名

## 今日確認する依頼
- **〇〇さん**：依頼内容 ― 事前確認／完了確認・状況（D-001）

## その他のタスク
- [ ] **タスク内容** ― P1・期限 MM/DD・案件名

---

## 記録

### Notion からの更新
- HH:MM 定期同期：変化の要約

### 決定事項・メモ
- [案件名] 会議・チャットで決まったことを一行で
- [案件名] 〇〇さんに△△を依頼（期限: MM/DD）  ← 書いておけば /sync-tasks が「渡した業務」に登録する

### 明日以降の予定
- **MM/DD（曜）** 予定・期限

### 振り返り（/end-day が書く）
```
- 上が「今日やること」、下が「記録」。毎日見るのは `---` より上だけでよい
- 🔴 は期限・確認日が今日以前のものに付ける
- 🟡 は、ノートを作る日が土日・祝日のときだけ使う。期限・確認日が翌営業日のものに付ける
- 絵文字はこの2種類だけにする
- 「記録」の中では、行頭に `[案件名]` を付けると、AI が案件ごとに振り分けやすい
- 2026-10-12 より前のノートは古い書式（見出しがすべて `##`）のまま
- 人に何かを頼んだら「〇〇さんに△△を依頼」とメモするだけでよい
