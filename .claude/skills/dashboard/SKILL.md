---

# 手順
1. /Tasks/todo.md・/Tasks/delegated.md・/Projects/README.md・今日の Daily Note を読む。
2. /Tasks/dashboard.md を次の構成で書き直す：
   - 最終更新日
   - 今日のトップ3（今日の Daily Note から。無ければ「未決定」）
   - 要対応：期限切れ／確認日が来た依頼／P? の件数と内容
   - 案件別の業務一覧：案件ごとの自分のタスク数（P1/P2/P3/P4）、渡した業務の数、直近の期限
3. 要対応が1件以上あれば、その内容を先に報告し、次にやること（/follow-up・/prioritize など）を提案する。
4. 要対応が0件なら「要対応なし」と、トップ3の進み具合を報告する。
