---

# 手順
1. /notion-sync の手順を実行する。
2. 今日の Daily Note を読む（無ければ「今日のノートがまだありません。/start-day を実行しますか」と聞いて終わる）。
3. 次の順で、短く箇条書きで報告する：
   1. **今日のトップ3の進み具合**：Notion のチェックと Daily Note から、終わったもの・残っているもの
   2. **確認日が今日以前の依頼**：まだ確認していないものについて、/follow-up の手順で確認メッセージの下書きを作る。Teams・Outlook に貼り付けて使う前提の文面にする（送信はユーザー）
   3. **確認待ち**（/Tasks/notion-sync.md）：完了扱い・依頼の登録など。まとめて「全部その案でよいか」を聞けるように、AI の案を添えて一覧にする
   4. **今日中に決めること**：P? のタスク、今日が期限で手が付いていないもの
4. 午後の段取りを1〜2行で提案する（トップ3の残りを優先。割り込みが多ければトップ3の入れ替えを質問する。優先度は勝手に変えない）。
5. ユーザーの返答を反映する：todo.md・delegated.md・done/・dashboard.md を更新し、確認待ちから消す。今日の Daily Note の「決定事項・メモ」に昼の確認で決めたことを書く。
6. 変更したファイルの一覧を報告する（コミットは夕方の /end-day でまとめて提案する）。
