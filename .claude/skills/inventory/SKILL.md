# 手順
最初の1回と、業務一覧に自信がなくなったとき（目安：月1回）に使う。

1. /Tasks/todo.md・/Tasks/delegated.md・/Projects/README.md を読み、今登録されている業務を案件別に一覧で示す。
2. 案件ごとに、次の質問を順に投げる（1案件ずつ、答えやすいように）：
   - この案件で、今自分が持っている作業は他にありますか？
   - この案件で、誰かにお願いしていて返事や成果物を待っているものはありますか？（依頼先・期限も）
   - 「そのうちやらないと」と思っているものはありますか？
3. 案件に属さない業務（定例業務・社内手続き・他部門からの頼まれごと）についても同じ質問をする。
4. 出てきた業務をすべて登録する：
   - 自分の作業 → /Tasks/todo.md（優先度の案と理由を出して確認する）
   - 渡した業務 → /Tasks/delegated.md（次回確認日も決める）
   - 新しい案件が出てきたら /Projects/ にフォルダーを作り、/Projects/README.md に追記する
5. /Tasks/dashboard.md を更新し、「自分のタスク◯件（P1◯件…）、渡した業務◯件」と総数を報告する。
6. P1 が9件以上（上限8件）なら、P1 の中で優先順位の低いものから P2 に下げる案を出して質問する。
