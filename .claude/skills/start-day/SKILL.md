# 手順
0. `git status` と `git fetch` で、リモートに未取り込みのコミット（別のPCでの作業）が無いか確認する。あれば「先に pull しますか」と聞き、許可が出たら `git pull` する。未コミットの変更があって pull できなければ、その旨を報告する。
   続けて /notion-sync の手順を実行し、Notion の週次ページの最新状況を取り込む。
1. `/DailyNotes/` の最新の週次フォルダーを確認する。今日が新しい週なら、ISO週番号で新しい週フォルダー（例: `2026-W42`）を作る。
2. 直近の日次ノートを読み、未完了のタスク（`- [ ]`）と「決定事項・メモ」の中でまだ /Tasks に登録されていない業務を拾い、/Tasks/todo.md か /Tasks/delegated.md に登録する（優先度が分からなければ P?）。
3. /Tasks/todo.md と /Tasks/delegated.md を読み、次の3つを洗い出す：
   - 期限が今日以前の自分のタスク
   - 次回確認日が今日以前の依頼（渡した業務）
   - 優先度が P? のタスク
4. ユーザーに次の順で提示する（短く、箇条書きで）：
   1. 確認日が来た依頼 → 依頼先と内容、事前確認か完了確認かを示し、「進捗確認の下書きを作りますか？」と添える（作る場合は /follow-up の手順に従う）。
      /Tasks/notion-sync.md の「事後報告」（目印から自動登録した依頼）があれば、ここで一行ずつ伝えて「事後報告」から消す
   2. 期限切れのタスク → 今日やる／期限を変える／人に渡す のどれにするか質問する
   3. P? のタスク → それぞれ優先度の案と理由を出し、確認をとる
   4. /Tasks/notion-sync.md の確認待ち → AI の案を添えて一覧にし、まとめて確認をとる
   5. 今日のトップ5の案（P1 → 期限が近い P2 の順）→ ユーザーに決めてもらう
5. ユーザーの回答を /Tasks/todo.md に反映し、/Tasks/dashboard.md を更新する（手順は /dashboard と同じ）。
6. 今日の日付（`YYYY-MM-DD.md`）で新規ノートを作成する：
   書式は /DailyNotes/README.md の「ノートの書式」に従う。上に「今日やること」、下に「記録」を置く。
   - 冒頭の引用ブロック：今日の要点を太字で1〜2行（トップ5／確認する依頼 N件／今日が期限 N件）
   - ## 今日のトップ5（ユーザーが決めたもの）
   - ## 今日確認する依頼
   - ## その他のタスク（P1 の残りと、期限が近い P2）
   - `---` で区切り、## 記録 の下に ### Notion からの更新（/notion-sync が追記する）・### 決定事項・メモ（空欄）・### 明日以降の予定
   見やすさの決まり：
   - タスク名を太字にし、期限・優先度・案件名は ` ― ` の後ろに添える（行頭に `[案件名]` は付けない）
   - 🔴 は期限・確認日が今日以前のものに付ける
   - 🟡 は、実行日が土日・祝日のときだけ使う。期限・確認日が翌営業日のもの（トップ5・確認する依頼・その他のタスク）に付ける。祝日は日本の祝日のほか、Notion の曜日タブに「祝日」と書かれていればそれも含める
   - 絵文字はこの2種類だけにする。冒頭の引用ブロックに「🟡 ＝ 翌営業日（MM/DD）が期限・確認日」と凡例を1行入れる
   - 依頼は「**依頼先**：内容 ― 事前確認か完了確認か・状況（D-xxx）」の1行にする。番号は末尾に添えるだけにする
   - 「記録」の中の行は、今までどおり行頭に `[案件名]` を付ける
7. 作成したノートへのリンクと、トップ5を報告する。リンクは毎回必ず出す（ユーザーは毎日このノートを見て動く）。
   - 書き方は `[2026-10-13.md](DailyNotes/2026-W42/2026-10-13.md)` のように、作業フォルダーからの相対パスにする（空白を含むパスはアプリで開けない。フォルダー名を DailyNotes にしたのはこのため）
   - ファイルを送るツール（SendUserFile）が使えるときは、ノートのファイルも送る
   - 定期実行で 4. の提示まで進めて返答を待つ場合も、ノートを作った時点でリンクを出す定期実行（毎朝 8:30）で始まった場合は、4. の提示まで進めてユーザーの返答を待つ。ユーザーがトップ5を決めずに先へ進もうとしたら、一度だけ「トップ5を決めておきますか？」と確認する。
