# 手順
1. 今週の週次フォルダー（/Daily Notes/YYYY-Wxx/）の全ノート、/Tasks/todo.md、/Tasks/delegated.md、/Tasks/done/ の今週分を読む。
2. 案件ごと（/Projects/README.md の一覧順）に以下をまとめる：
   - 今週の進捗（完了したこと）
   - 渡した業務の状況（順調／遅延／確認待ち）
   - 遅れ・リスク（期限切れタスク、1週間以上動いていない依頼）
   - 来週の重点
3. 業務一覧の健全性をチェックして報告する：
   - 1週間以上更新のない P1・P2 のタスク（本当にその優先度か）
   - 次回確認日が未設定、または過ぎたままの依頼
   - P? が残っているタスク
4. 優先度の見直しをユーザーに提案する（/prioritize の手順で）。
5. 結果を今週フォルダーの `weekly-review.md` に保存し、/Tasks/dashboard.md を更新して、要点を3行で報告する。
