# 手順
1. 今週の週次フォルダー（`/Daily Notes/YYYY-Wxx/`）の全ノートと `/Tasks/todo.md`、`/Tasks/done/` の今週分を読む。
2. 案件ごと（`/Projects/README.md` の一覧順）に以下をまとめる：
   - 今週の進捗（完了したこと）
   - 遅れ・リスク（期限切れタスク、「待ち」が長いもの）
   - 来週の重点
3. 案件をまたぐ論点（部門間の調整が必要なこと等）があれば別にまとめる。
4. 結果を今週フォルダーの `weekly-review.md` に保存し、要点を3行で報告する。
