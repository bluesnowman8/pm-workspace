# 手順
1. 対象の案件名を確認する（指定がなければ質問する）。
2. `/Projects/<案件>/README.md`、`meetings/` の直近の議事録、前回会議以降の `/Daily Notes/` の該当案件のメモ、`/Tasks/todo.md` の該当案件のタスクを読む。
3. 以下の構成でたたき台を作る：
   - 前回からの進捗
   - 前回の宿題の状況
   - 課題・リスクと対応案
   - 今回決めたいこと（論点）
   - 次回までの宿題（担当・期限）
4. 出席者に上司・他部門・社外が含まれる場合は `/Context/people.md` と `/Context/writing-style.md` に従う。
5. `/Projects/<案件>/meetings/YYYY-MM-DD_定例_資料.md` に保存し、パスを報告する。
