name: add-new-daily-note
description: 前日のノートを参照し、本日の Daily Note 雛形を自動生成する
---

# 手順
1. `/Daily Notes/` 内の最新の週次フォルダー（例: `2026-W41`）を確認する。今日が新しい週なら、ISO週番号で新しい週フォルダーを作る。
2. 直近の日次ノートを取得し、未完了のタスク（`- [ ]`）を抽出する。
3. `/Tasks/todo.md` から、期限が今日または過ぎているタスクを抽出し、2 と重複しないものを加える。
4. 本日の日付（`YYYY-MM-DD.md`）で新規ノートを作成し、以下の構成で出力する：
   - ## 本日の優先タスク（前日からの引き継ぎ＋期限が今日のもの。優先度の高い順）
   - ## 決定事項・メモ（空欄）
   - ## 明日以降の予定
5. 作成したファイルのパスと、引き継いだタスクの件数を報告する。
