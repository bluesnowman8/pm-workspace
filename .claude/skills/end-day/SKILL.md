# 手順
1. /notion-sync の手順を実行する。
2. 今日の Daily Note と /Tasks/notion-sync.md の「確認待ち」を読む。
3. /sync-tasks の手順で、今日のノートの「決定事項・メモ」・/Inbox・今日追加された議事録から、新しいタスク・人に渡した業務・状態変化を拾う。
4. 次の順で報告し、確認をとる（質問はまとめて1回にする）：
   1. **今日のトップ3の結果**：終わった／残った。残ったものは「明日もトップ3にする／期限を変える／人に渡す」のどれにするか
   2. **完了の確認**：Notion で `[x]` になったもの、メモで完了と分かるもの → 完了扱いにしてよいか
   3. **確認待ち**の残り全部（AI の案付き。「全部その案で」と一言で答えられるようにする）
   4. **新しく拾ったタスク・依頼**：優先度の案と、依頼なら次回確認日の案
   5. **今日中に決める P?**：残っていれば必ず判断を求める
5. 返答を反映する：todo.md・delegated.md・done/YYYY-MM.md・dashboard.md を更新し、notion-sync.md の確認待ちを消す。案件の状態が変わったら /Projects/README.md を更新する。
6. **明日の準備**を今日の Daily Note の「## 明日以降の予定」に書く：
   - 明日が期限のタスク、明日が確認日の依頼
   - 明日のトップ3の候補（P1 → 期限が近い P2 の順。決めるのは翌朝の /start-day）
7. 今日の Daily Note の末尾に「## 振り返り」を作り、トップ3の結果と、ユーザーが言った気づきを1〜3行で書く（試験運用中の気づきは `[試験運用]` を付ける）。
8. 変更したファイルの一覧を示し、「コミットして push してよいか」を確認する（自宅PCと共有するため）。許可が出たらコミットし、push する。許可がなければ push しない。
