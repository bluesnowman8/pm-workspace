---

# 前提
- Outlook・Teams は外部サービスに接続できない（社内ルール）。中身は、ユーザーがこの会話に貼り付けるか、/Inbox にファイルで置いたものだけを扱う。
- 取り込まないもの：電話番号、メールアドレス、URL、添付ファイルの中身（概要と置き場所だけ書く）。

# 手順
1. 貼り付けられた文面か、/Inbox のファイル（指定が無ければ全部）を読む。
2. 内容ごとに振り分け、一覧で示す：

   | 種類 | 扱い |
   |---|---|
   | 自分がやること | todo.md への登録案（優先度の案と理由） |
   | 人に頼んだこと | delegated.md への登録案（依頼先・内容・期限・次回確認日の案） |
   | 既存の依頼への返事 | 該当する D-xxx と、経緯に追記する内容・状態の変更案 |
   | 返信が必要なもの | 返信の下書き（/Context/people.md と /Context/writing-style.md に従う。送信はユーザー） |
   | 予定（会議・締切） | Outlook に入れる予定の案（件名・日時・場所）。登録はユーザーが行う |
   | 案件の決定事項・参考情報 | /Projects/<案件>/ への追記案。今日の Daily Note の「決定事項・メモ」にも1行書く |

3. ユーザーの確認をとってから反映する。/Projects 内の既存ファイルは、追記でも必ず許可をとる（上書き・削除はしない）。
4. 反映したら dashboard.md を同期する。/Inbox のファイルを処理し終えたら、削除してよいかを確認する。
5. glossary.md に無い略語が出てきたら、意味を質問して追記を提案する。
6. 変更したファイルの一覧を報告する。
