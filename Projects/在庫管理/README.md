# 在庫管理

## 概要・目的
ノートPCの在庫・販売計画・実績を把握し、在庫切れと過剰在庫を防ぐ。週次更新の結果をもとに購買へ発注を依頼する。
（Notion 週次ページから推定。要確認）

## スコープ
- 含む: 在庫状況把握（SAP在庫・購買計画・販売実績・週次仕掛け）、在庫使用計画（ONE/NoteOne 計画）、アラート、月次報告、予算との比較、価格推移
- 含まない: ACアダプタ単品販売（→ 部門間調整）、ツール開発（→ 業務効率化）

| いつ | 内容 |
|---|---|
| 毎週月曜 | 週次更新 → 購買に発注を依頼 |
