## 各案件フォルダーの構成
- `README.md` : 概要・目的・関係者・現在のフェーズ・直近の状況
- `docs/` : 仕様書・設計書・資料（Markdown化したもの。Office文書はPDF化）
- `meetings/` : 議事録（`YYYY-MM-DD_会議名.md`）
- `incidents/` : 障害・トラブルの記録（過去事例の検索用）
