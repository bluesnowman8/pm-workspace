# 用語集・社内略語

試験運用の初期データとして、Notion 週次ページに出てくる用語を登録した。「要記入」は意味を確認して書く。

| 用語・略語 | 意味 | 使われる場面 |
|---|---|---|
| MOQ | 最小発注数量（Minimum Order Quantity） | 発注 |
| EOL | 販売・生産終了（End of Life） | EOLリスト、リペア移動 |
| PSE | 電気用品安全法の適合マーク | ACアダプタのシール |
| SAP | 基幹システム（在庫状況の取得元） | 週次更新 |
| ベア | 要記入（ベースとなる本体？） | 発注、リペア、Secured Core |
| しかけ（仕掛け） | 要記入 | 週次更新、ISOP |
| ISOP | 要記入（社内システム。型番メンテナンス等） | モデル更新確認、在庫数設定 |
| ISM | 要記入（社内システム。所要量照会等） | 在庫数設定 |
| ONE計画 / NoteOne計画 | 要記入 | 在庫使用計画 |
| SKUリスト | 要記入 | 価格推移、10月PJ |
| Secured Core | 要記入 | V75・V755・B/DA5 の問題 |
| SCL | Secured Core Level。「SCL3」のようにレベルの数字を付けて使う | Secured Core 問題（例：法人も SCL2 で OK） |
| MTL | Intel の Meteor Lake 世代の CPU | V74/75 の MTL |
| MC | 要記入 | SKU追跡アプリ、価格 |
| Gfk | 市場シェアの調査データ | 販売台数の推定 |
| ITS / IGS | 要記入（本人も確認中） | 金曜タブの疑問 |
| リペア移動 | 要記入 | 月1回のリペア移動MTG |
| exment | 社内申請システム（資格取得・経費精算などの申請） | AIパスポートの申請 |
