# Daily Notes（索引）

日常のメモ・作業ログの起点。ここに書いた最新情報を AI が Projects / Tasks へ転記する。
毎朝 `/start-day` で作る。

## 命名規則
- 週フォルダー: `YYYY-Wxx`（ISO週番号。例: `2026-W41`）
- 日次ノート: `YYYY-Wxx/YYYY-MM-DD.md`
- 週の振り返り: `YYYY-Wxx/weekly-review.md`

## ノートの書式
```markdown
# YYYY-MM-DD

## 今日のトップ3
1. [案件名] タスク内容

## 今日確認する依頼
- D-001 〇〇さん：依頼内容

## その他のタスク
- [ ] [案件名] タスク内容

## 決定事項・メモ
- [案件名] 会議・チャットで決まったことを一行で
- [案件名] 〇〇さんに△△を依頼（期限: MM/DD）  ← 書いておけば /sync-tasks が「渡した業務」に登録する

## 明日以降の予定
- 
```
- 行頭に `[案件名]` を付けると、AI が案件ごとに振り分けやすい
- 人に何かを頼んだら「〇〇さんに△△を依頼」とメモするだけでよい
