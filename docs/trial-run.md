- 7月の日付が入っている古い項目は「要確認（古い可能性）」として todo.md の P? に残した

## 試験運用の手順
1. clone（または pull）して、Claude Code デスクトップアプリでフォルダーを開く
2. `/start-day` を実行する
   - 確認日が来た依頼（D-001・D-002・D-004）が最初に出てくるか
   - P? のタスクについて優先度の判断を求められるか
   - 今日のトップ3を決めて、`Daily Notes/2026-W41/2026-10-08.md` が作られるか
3. `/prioritize` で P? をすべて P1〜P4 に振り分ける（P1 が多すぎると指摘されるか）
4. 日中、今日のノートに「〇〇さんに△△を依頼」と書き、夕方に `/sync-tasks` → `delegated.md` に登録されるか
5. 金曜に `/weekly-review`

## 評価のしかた（1週間後）
| 要件 | 確認すること |
|---|---|
| R1 業務一覧 | Notion を見なくても、dashboard.md と todo.md だけで今週の業務が分かったか |
| R2 渡した業務 | 確認日が来た依頼を、言われる前に確認できたか。忘れていた依頼はなかったか |
| R3 優先順位 | 毎朝トップ3を決めたか。P? が翌日まで残った日はなかったか |
| R4 GUI 運用 | デスクトップアプリだけで回せたか。面倒だった操作は何か |

気づいたことは各日の Daily Note の「決定事項・メモ」に `[試験運用]` を付けて書く。`/weekly-review` で拾ってまとめる。
